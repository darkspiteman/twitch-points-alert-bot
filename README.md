# Twitch Alert Bot — инструкция

Ваша собственная замена Sound Alerts. Работает на вашем компьютере вместе с OBS: когда зритель
активирует награду за баллы канала, в OBS проигрывается звук, видео или анимация. Без облачных
сервисов и без платного хостинга.

---

## Установка (один раз)

1. Откройте папку программы и дважды щёлкните **`install.cmd`**.
   Установщик подготовит всё нужное и создаст ярлык **«Twitch Alert Bot»** на рабочем столе.
2. Запустите **«Twitch Alert Bot»** с рабочего стола.
   - Рядом с часами появится фиолетовый значок со звездой.
   - В браузере откроется **панель управления** (`http://127.0.0.1:17420/panel/`).

> Если Windows спросит про доступ в сеть — выберите только «Частные сети» или «Отмена».
> Боту не нужен доступ извне: он работает только внутри вашего компьютера.

## Подключение к Twitch (один раз)

Бот входит в Twitch через официальный механизм: вы подтверждаете вход на сайте twitch.tv,
бот **никогда не видит ваш пароль**.

1. Откройте <https://dev.twitch.tv/console/apps/create> и войдите в свой аккаунт Twitch
   (Twitch может попросить включить двухфакторную аутентификацию).
2. Заполните форму:
   - **Название** — любое уникальное, например `Alert Bot ВашНик`;
   - **OAuth Redirect URLs** — `http://localhost` (поле обязательное, бот его не использует).
     Если появилась ошибка «URL-адреса должны использовать протокол HTTPS» — удалите пустую строку адреса
     или впишите `https://localhost`;
   - **Категория** — `Broadcaster Suite`;
   - **Тип клиента** — **«Общедоступный» (Public)**.
3. Нажмите «Создать», затем «Управление». Скопируйте **Client ID**. Секрет клиента не нужен.
4. В панели бота: **Настройки → Twitch** → вставьте Client ID → нажмите **«Войти через Twitch»**.
5. Появится код из 8 символов. Нажмите **«Открыть twitch.tv/activate»**, проверьте код и нажмите «Разрешить».
6. Через пару секунд на главной будет: **Twitch — Подключён, EventSub — Активен**.

## Добавление в OBS (один раз)

1. В OBS: в списке «Источники» нажмите **«+» → «Браузер»**, назовите, например, **«Alert Bot»**.
2. **URL:** `http://127.0.0.1:17420/overlay` (кнопка «Копировать» есть в «Настройки → OBS overlay»
   и в меню значка в трее).
3. **Ширина 1920, высота 1080.** Источник растягивается на весь кадр.
4. Включите **«Управлять аудио через OBS»**.
5. **Выключите «Отключать источник, когда он не виден»** и «Обновить браузер, когда сцена становится активной».
6. Нажмите ОК. Растяните источник на весь экран (ПКМ → «Преобразовать» → «Растянуть на весь экран»).
7. Чтобы слышать оповещения в наушниках: ПКМ по источнику → «Расширенные свойства аудио» →
   «Мониторинг звука» → **«Монитор и вывод»**.
8. В остальные сцены добавляйте **тот же** источник: «+» → «Браузер» → «Добавить существующий» → «Alert Bot».
   Два разных источника с этим адресом = двойной звук (панель предупредит об этом).
9. На главной странице панели нажмите **«Тестовое оповещение»** — в OBS появится картинка и прозвучит сигнал.

После перезапуска OBS источник сам переподключается к боту.

## Настройка наград

1. **Медиа** → перетащите файлы (MP3, WAV, OGG, WebM, MP4/H.264, GIF, PNG, JPG, WebP; до 200 МБ).
   Бот проверит каждый файл и предупредит, если он повреждён или кодек не поддерживается.
2. **Награды** → «Обновить из Twitch». Для каждой награды:
   - **Медиафайл** — видео, GIF, картинка или звук;
   - **Дополнительный звук** — если основной файл картинка/GIF;
   - **Громкость**, **длительность** (0 = до конца видео/звука), **задержка**, **антиспам**;
   - флажок **«Включена в боте»**;
   - кнопка **«▶ Тест»** — проверка в OBS без списания баллов.

Новые награды по умолчанию **выключены** в боте — включите их флажком «Включена в боте».

### Видео или только звук

- **Звук (основной файл)** — что играет в режиме «Только звук».
- **Видео / GIF / картинка** — что показывается в режиме «С видео». У видео играет его собственный звук.
- **Звук к видео/GIF** — необязательный звук поверх картинки или GIF.
- Переключатель **«🎬 С видео / 🔊 Только звук»** у каждой награды.
- **«Убрать зелёный фон (хромакей)»** — для роликов на зелёном фоне (green screen): зелёный станет прозрачным.
- **Главная → карточка «Видео» → «Только звук для всех»** — быстро выключить видео у всех наград (например, на игровой сцене).
- Если видеофайл повреждён или удалён, награда всё равно прозвучит — бот сыграет звук и запишет предупреждение в журнал.

### Новая награда
«Награды» → **«+ Новая награда в Twitch»** — название, стоимость, перезарядка. Затем назначьте медиафайл и включите награду.
Значок награды загружается вручную в панели автора Twitch (через API это невозможно).

## Переход с Sound Alerts

Если сейчас награды обслуживает Sound Alerts (или похожий сервис) — подробный план в [docs/MIGRATION.md](docs/MIGRATION.md). Коротко:

1. Настройте медиа для наград в боте, Sound Alerts пока не трогайте.
2. Включите **«Режим наблюдения»** (Главная → Режим). Бот записывает активации в журнал, но не играет их.
   Проведите стрим и убедитесь, что все активации видны в журнале.
3. В OBS **скройте** (глаз) источники Sound Alerts во всех сценах.
4. Включите награды в боте и **«Активный режим»**. Проверьте тестом.
5. Удалять награды Sound Alerts или отключать Sound Alerts — только после нескольких удачных стримов.

## Управление наградами

Награды, **созданные ботом**, можно менять прямо из панели («Награды»): название, стоимость, пауза.
Бот отмечает их погашения выполненными и возвращает баллы, если оповещение не сыграло.

**Новая награда:** «Награды» → «+ Новая награда в Twitch». Награды, созданные вручную на сайте Twitch или другим сервисом, бот тоже воспроизводит, но не может ими управлять (возврат баллов, изменение из панели) — для этого есть кнопка «Создать свою копию в Twitch…».

## Повседневное использование

- Запускайте «Twitch Alert Bot» с рабочего стола (или включите **Настройки → Система → Запускать вместе с Windows**).
- **Цвет точки на значке в трее:** зелёный — всё подключено; жёлтый — что-то не подключено (например, OBS закрыт);
  красный — бот не отвечает (лаунчер перезапустит его сам).
- **Меню значка:** открыть панель, скопировать адрес для OBS, перезапустить бота, папка логов, выход.
- **Главная:** состояние, очередь (пауза / пропустить / очистить), последние события, кнопки теста.

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| «Twitch: Не настроен» | Укажите Client ID (Настройки → Twitch) |
| «Twitch отклонил запрос входа» | Проверьте Client ID и что тип клиента приложения — «Общедоступный» |
| «Срок входа истёк» | Нажмите «Войти через Twitch» ещё раз (если бот не запускался больше 30 дней) |
| «OBS overlay: Не подключён» | Проверьте адрес в Browser Source, что OBS запущен и источник не отключается, когда не виден |
| Звук дважды | В OBS есть второй источник с адресом бота или ещё работает Sound Alerts |
| Оповещения не играют | Проверьте «Режим» на главной (должен быть «Активный»), флажок «Включена в боте» и медиафайл |
| «Порт занят» | Настройки → Система → другой порт, перезапустите бота и поменяйте адрес в OBS |
| Файл «повреждён» | Пересохраните файл (видео — в MP4 H.264 или WebM) и загрузите снова |

Логи: меню значка → «Открыть папку логов» (или папка `data\logs` в папке программы). Токены в логи не пишутся.

## Где что хранится

| Что | Где |
|---|---|
| Программа | папка, где лежит `install.cmd` |
| Настройки, история, медиа, логи | папка `data\` внутри папки программы |
| Вход в Twitch | `data\tokens.dpapi` — зашифровано Windows (DPAPI), расшифровать может только ваш пользователь Windows |
| Резервные копии сцен OBS | `data\obs-backups` в папке программы (кнопка в «Настройки → OBS») |

> Чтобы перенести бота на другой компьютер или сделать резервную копию — скопируйте папку программы целиком
> (вход в Twitch на другом компьютере придётся выполнить заново: он зашифрован под вашего пользователя Windows).

```
npm run build:launcher
```
