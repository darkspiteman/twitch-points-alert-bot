# Переход с TriggerFyre на Twitch Alert Bot

Инструкция для тех, у кого награды за баллы канала сейчас показываются через **TriggerFyre**
(overlays.thefyrewire.com). В конце вы полностью откажетесь от TriggerFyre, а награды будет
проигрывать бот на вашем компьютере.

Главное правило: **в каждый момент награду проигрывает кто-то один** — TriggerFyre или бот.
Тогда не будет ни двойного звука, ни пропусков. Ничего не удаляйте, пока бот не отработает
хотя бы один-два стрима.

---

## Как устроен TriggerFyre и что это значит для переезда

* **Награды — обычные награды Twitch.** TriggerFyre сам награды не создаёт: вы создаёте их в панели автора
  Twitch, а в TriggerFyre у каждого триггера указано **«Reward name»** — точное название награды.
  Бот увидит эти же награды сразу после входа в Twitch. Создавать их заново не нужно.
* **Медиафайлы лежат на сайте TriggerFyre** (вы загружали их в разделы Images / Videos / Sounds).
  Их нужно сохранить к себе на компьютер и загрузить в бота.
* **TriggerFyre показывается в OBS через «Overlay URL»** — источник «Браузер» с адресом thefyrewire.
  В конце его нужно убрать из OBS, иначе будет двойной звук.
* TriggerFyre умеет больше, чем «награда → звук/видео» (см. таблицу ниже). Бот переносит
  **только оповещения за баллы канала**. Если вы пользовались чат-командами или действиями в OBS —
  прочитайте раздел «Что бот не умеет».

### Что переносится

| В TriggerFyre | В боте |
|---|---|
| Reward name (название награды) | Награда появляется сама: «Награды» → «Обновить из Twitch» |
| Картинка / GIF | «Видео / GIF / картинка» у награды |
| Видео (MP4, WEBM) | «Видео / GIF / картинка» + режим «🎬 С видео» |
| Звук (MP3, WAV, OGG) | «Звук (основной файл)» |
| Optional sound (звук к картинке) | «Звук к видео/GIF» |
| Volume (%) | «Громкость» у награды; общая громкость — «Настройки → Overlay» |
| Duration / Hold duration | «Длительность, с» у награды (0 — до конца видео/звука) |
| Delay (ms) | «Задержка перед показом, с» у награды (в боте — секунды: 1500 мс = 1,5 с) |
| User cooldown | «Антиспам: повтор от зрителя не чаще, с» у награды или общий в «Настройки → Очередь и защита от спама» |
| Global cooldown | Перезарядка самой награды в Twitch (настраивается в Twitch) |
| Allow triggers to overlap/queue | В боте всегда очередь: оповещения идут строго по одному |
| Size (%) | Общий размер для всех: «Настройки → Overlay → Макс. ширина / высота, % экрана» |
| X / Y position, Random position | Общее положение для всех: «Настройки → Overlay → Положение» (центр, верх, низ, углы) |
| Enter / Exit animation | В боте одна плавная анимация появления и исчезновения для всех |
| Видео на зелёном фоне | Галочка «Убрать зелёный фон (хромакей)» у награды |
| Enable / disable trigger | Флажок «Включена в боте» |

### Что бот не умеет (и что с этим делать)

| Функция TriggerFyre | Замена |
|---|---|
| **Чат-команды** (Command name, aliases, combo keywords, user level, permit list) | Бот реагирует только на баллы канала. Для команд в чате — ваш чат-бот (StreamElements, Nightbot, Streamer.bot) |
| **Действия в OBS** (переключить сцену, показать/скрыть источник, включить фильтр) | Не поддерживается. Если нужны — Streamer.bot или плагин «Advanced Scene Switcher» для OBS |
| **Группы** (Random — случайный файл из нескольких, Multi) и **% Chance** | Не поддерживается: у каждой награды один файл (картинка/видео + звук) |
| **Trigger limit** (один раз за сессию / на зрителя) | Не поддерживается. Близкий вариант — лимиты самой награды в Twitch («Макс. активаций за стрим», «на пользователя») |
| Разное положение/размер у каждого триггера | В боте положение и размер общие для всех наград |
| Редакторы (Editors — модераторы правят триггеры) | Нет: панель бота работает только на вашем компьютере |
| Overlay commands (`!tf clear` и т. п.) | Управление очередью — на главной панели бота: пауза, пропустить, очистить |

## Шаг 0. Подготовка (TriggerFyre пока работает как обычно)

1. **Установите бота** и подключите его к Twitch и OBS — по [README](../README.md):
   «Установка», «Подключение к Twitch», «Добавление в OBS». Тестовое оповещение должно появиться в OBS.
2. **Сразу включите «Режим наблюдения»**: панель бота → «Главная» → карточка «Режим» → кнопка **«Включить наблюдение»**.
   В этом режиме бот только записывает активации и ничего не проигрывает — двойного звука не будет.
3. **Сделайте резервную копию сцен OBS**: «Настройки» → «OBS Studio» → «Резервная копия сцен OBS».

## Шаг 1. Перепишите свои триггеры

Откройте TriggerFyre (overlays.thefyrewire.com/widgets/triggerfyre → Login with Twitch) и для каждого
триггера выпишите в таблицу (блокнот или Excel):

| Reward name | Тип (картинка/видео/звук) | Файл | Звук к картинке | Volume | Duration | Delay | Cooldown |
|---|---|---|---|---|---|---|---|

Удобно сделать скриншот настроек каждого триггера.

## Шаг 2. Сохраните медиафайлы к себе

Создайте папку, например `Документы\Алерты`, и сохраните туда все файлы, которые используются в триггерах:

* если у вас остались **исходные файлы** (то, что вы когда-то загружали в TriggerFyre) — просто возьмите их;
* иначе откройте в TriggerFyre разделы с медиа (**Images / Videos / Sounds**), откройте файл
  (предпросмотр) и сохраните его: правой кнопкой мыши → «Сохранить как…» (для видео — «Сохранить видео как…»).
  Если сайт не даёт сохранить файл, найдите исходник заново (например, там, откуда вы его брали).

Называйте файлы понятно — как награды, — чтобы потом не перепутать.

## Шаг 3. Загрузите файлы в бота и привяжите к наградам

1. Панель бота → **«Медиа»** → перетащите туда все файлы. Бот проверит каждый: если файл повреждён
   или кодек не поддерживается (например, видео H.265), он скажет об этом.
   Видео лучше в **MP4 (H.264)** или **WebM**.
2. **«Награды» → «Обновить из Twitch».** Появятся все награды канала, в том числе те, что использовал
   TriggerFyre. У них будет метка **«Другое приложение»** — это нормально: награда создана на сайте
   Twitch, бот её проигрывает, но не может менять (подробнее — в шаге 6).
3. У каждой награды из вашей таблицы:
   * выберите **«Звук (основной файл)»** и/или **«Видео / GIF / картинка»**;
   * для картинки или GIF со звуком — **«Звук к видео/GIF»**;
   * поставьте режим **«🎬 С видео»**, если нужна картинка/видео, или **«🔊 Только звук»**;
   * перенесите громкость, длительность, задержку и антиспам из таблицы;
   * для ролика на зелёном фоне — галочка **«Убрать зелёный фон (хромакей)»**;
   * поставьте флажок **«Включена в боте»**.
4. **«Настройки» → «Overlay»**: выберите положение и размер оповещений — так, как было в TriggerFyre.
5. Вне эфира нажмите у каждой награды **«▶ Тест»** — проверьте в OBS картинку, звук и громкость.
   Тест не списывает баллы, но во время эфира его видят зрители.

## Шаг 4. Проверка на стриме (бот только смотрит)

Проведите один стрим как обычно: оповещения показывает TriggerFyre, бот в «Режиме наблюдения».
После стрима откройте в боте «Главная» → «Последние активации наград»: там должны быть **все**
активации за стрим. Если какой-то нет — проверьте вход в Twitch («Настройки» → «Twitch»).

## Шаг 5. Переключение на бота

Перед следующим стримом:

1. В OBS найдите источник «Браузер» с адресом **thefyrewire.com** (Overlay URL TriggerFyre) и
   **скройте** его (значок глаза) **во всех сценах**. Пока не удаляйте.
2. В боте: «Главная» → карточка «Режим» → **«Включить воспроизведение»** (режим станет «Активный»).
3. Нажмите «Тестовое оповещение» — проверьте, что звук один, без эха.
4. Проведите стрим.

**Если что-то пошло не так — откат за 10 секунд:** в боте нажмите «Включить наблюдение», в OBS снова
покажите источник TriggerFyre.

## Шаг 6. Полный отказ от TriggerFyre (после 2–3 удачных стримов)

1. **OBS:** удалите источник TriggerFyre из всех сцен.
2. **TriggerFyre:** выключите или удалите триггеры (по желанию — на сайт можно больше не заходить).
3. **Отключите доступ TriggerFyre к Twitch:** twitch.tv → аватар → «Настройки» → «Подключения» →
   внизу «Другие подключения» → найдите **thefyrewire / TriggerFyre** → **«Отключить»**.
4. Если вы связывали TriggerFyre со StreamElements — в StreamElements этот виджет/оверлей тоже можно удалить.

### По желанию: сделать награды «своими» для бота

Награды, созданные на сайте Twitch, бот проигрывает, но **не может** их менять из панели и **не может
вернуть баллы** зрителю, если оповещение не сыграло (например, файл повреждён). Также после обрыва
интернета бот не сможет «доиграть» такие активации — только запишет в журнал, что они могли потеряться.

Чтобы это заработало, сделайте награду «своей»:

1. «Награды» → у награды → **«Создать свою копию в Twitch…»** → подтвердите.
   Копия создаётся **на паузе** и с пометкой в названии (Twitch требует уникальных названий).
2. Назначьте копии те же файлы и настройки, включите её в боте.
3. В панели автора Twitch **удалите** старую награду.
4. В боте у копии: **«Переименовать…»** (вернуть исходное название) → **«Снять с паузы в Twitch»**.

> Значок (картинку) награды бот через Twitch API поставить не может — после этого загрузите его заново
> в панели автора Twitch: «Награды для зрителей» → «Баллы канала» → «Управление наградами».

## Частые вопросы

**Двойной звук.** В OBS остался видимым источник TriggerFyre, или источник бота добавлен в OBS дважды
разными источниками. Во всех сценах должен быть один и тот же источник бота («Добавить существующий»).

**Награда не играет.** Проверьте: режим «Активный», флажок «Включена в боте», назначен файл.
Название награды в Twitch менять можно — бот привязывает настройки к самой награде, а не к названию.

**Видео не показывается, а звук есть.** Возможно, видео в H.265/HEVC — пересохраните его в MP4 (H.264) или WebM.
Также проверьте, что у награды режим «🎬 С видео» и не включено «Только звук для всех».
