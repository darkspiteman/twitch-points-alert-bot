## Что проверено вручную на реальном канале и в OBS

* вход в Twitch (Device Code Flow, приложение типа Public) и подписка EventSub `channel.channel_points_custom_reward_redemption.add` v1 — ровно одна активная подписка;
* активация наград зрителями: событие приходит через ~1,5–2 с, звук/видео играет в OBS, погашения наград бота получают статус FULFILLED;
* создание, переименование, пауза наград бота через Helix;
* перезапуск OBS — overlay сам переподключается; аварийное завершение бота — лаунчер перезапускает его, вход и подписка восстанавливаются за несколько секунд;
* реальный обрыв сети — EventSub переподключается и создаёт подписку заново;
* видео MP4 H.264, хромакей (зелёный фон) — работает в OBS.
* «Найти медиа»: поиск Klipy (клипы, GIF, стикеры) и Freesound на настоящих ключах; мем Klipy проигрывается в OBS прямо с CDN Klipy; звук Freesound скачивается с автором и лицензией и играет в OBS; при битой ссылке Klipy overlay играет запасной звук.
* **Streamlabs Desktop**: «Веб-источник» с адресом бота определяется как Streamlabs (метка `SLD` в User-Agent), тестовые
  оповещения со звуком и видео играют, после перезапуска бота источник сам переподключается; бот сам находит
  `C:\Program Files\Streamlabs OBS\Streamlabs OBS.exe` и копирует сцены из `%APPDATA%\slobs-client\SceneCollections`.
* обновление одной кнопкой: окно «Доступно обновление», установка, перезапуск и окно «Что нового» (на тестовой копии программы).

## Известные ограничения

1. **PKCE не поддерживается Twitch.** Используется Device Code Flow (public client) — официальный способ
   Twitch для приложений на Windows, без секрета клиента.
2. **Пропущенные события.** Twitch не переотправляет события, пропущенные во время разрыва EventSub.
   Бот восстанавливает их только для наград, созданных им самим (Helix «Get Custom Reward Redemption»
   доступен только приложению-создателю). Для наград других сервисов (Sound Alerts и т. п.) в журнал записывается окно возможной потери.
3. **Чужие награды нельзя изменить** (созданные Sound Alerts или вручную на сайте Twitch): ни название, ни стоимость, ни статус погашения / возврат баллов.
4. **Refresh token живёт 30 дней без использования.** Если бот не запускался больше месяца — нужно войти заново.
5. **Видео H.265/HEVC** может не воспроизводиться в OBS (бот предупреждает при загрузке). Используйте MP4 H.264 или WebM VP9.
6. **Тестовое оповещение во время эфира видно и слышно зрителям** — тестируйте вне эфира или в отдельной сцене.
7. **Порт меняется после перезапуска** бота; адрес в OBS нужно поменять вручную.
8. Лаунчер написан на .NET Framework 4 (входит в Windows 10/11). Node.js 22.18+ нужен один раз для установки
   (затем используется собственная копия в `runtime\`).
9. В обычном браузере (не OBS/Streamlabs) звук overlay приглушён до клика «Включить звук» — это политика браузеров; в OBS и Streamlabs Desktop ограничения нет.
10. **Мемы Klipy работают только онлайн.** Правила Klipy (Integration Requirements) запрещают хранить копии файлов
    и раздавать их через свой сервер, поэтому бот хранит только идентификатор, а OBS загружает файл с CDN Klipy при показе.
    Без интернета или при сбое Klipy играет запасной звук награды («Звук (основной файл)»); если его нет — оповещение
    завершается ошибкой в журнале. Тестовый ключ Klipy — 100 запросов в час (каждый поиск и каждый показ мема).
    Хромакей для онлайн-видео не применяется (видео с чужого домена нельзя обработать WebGL без CORS).
11. **GIPHY и Tenor не подключены**: GIPHY запрещает хранить файлы и даже ссылки на них, Tenor API закрыт.
    Скачивание файлов Klipy/GIPHY/Tenor/MemeAlerts по ссылке бот отклоняет.
12. **Freesound** бесплатен только для некоммерческого использования API; звуки скачиваются как MP3-превью (~128 кбит/с),
    оригиналы требуют OAuth и не используются. Лимит — 60 запросов в минуту, 2000 в день.
13. **Streamlabs Desktop старых версий** может не писать метку `SLD` в User-Agent — тогда overlay считается «OBS»
    (оповещения всё равно идут в программу для стрима, а не в браузер; программа для кнопок выбирается в настройках вручную).
    Если OBS и Streamlabs открыты одновременно с источником бота, оповещение играет в обеих (панель предупреждает).
